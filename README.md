# Grave Shift Write-Ups

This repository contains walkthroughs from authorized security training labs and CTF challenges worked by Grave Shift. The articles focus on the investigation itself, including what I found, what failed, what changed my understanding of the challenge, and how the room was ultimately solved.

The write-ups are published only after the challenge has been cleared and the technical details have been checked against the evidence collected during the solve.
